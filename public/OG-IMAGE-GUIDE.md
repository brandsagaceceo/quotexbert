# OG Image Creation Guide

Create a 1200x630px image for social media sharing.

## Required File
Place at: `public/og-image.jpg`

## Design Requirements
- **Size**: 1200px × 630px
- **Format**: JPG or PNG
- **Safe Zone**: Keep important content within 1200x600px center

## Content to Include
- **Logo**: QuoteXbert logo (top left)
- **Headline**: "AI-Powered Home Repair Estimates"
- **Subheadline**: "Connect with Verified GTA Contractors"
- **Background**: Gradient from orange to red (matching brand)
- **Icons/Trust Badges**: 
  - "✓ Serving the GTA"
  - "🔒 Stripe-Secured"
  - "✓ Background-Checked"
  - "⭐ Verified Reviews"

## Quick Creation Tools
- Canva (canva.com) - Use "Facebook Post" template
- Figma (figma.com)
- Adobe Express
- Or use AI: "Create a 1200x630 social media banner for QuoteXpert home services"

## Alternative: Use Logo
Use the approved QuoteXbert wordmark in `public/branding/quotexbert-wordmark-display.webp` on a burgundy-and-white background.
